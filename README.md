# Week 1 Assessment — Python and Data Engineering

This repository contains the completed Week 1 assessment tasks covering Python fundamentals, API integration, data analysis, Jupyter Notebook, and Git workflows.

## Main Focus

- Python fundamentals and object-oriented programming
- File handling, APIs, JSON, and environment variables
- NumPy, Pandas, data cleaning, and visualization with Matplotlib
- Jupyter Notebook analysis and Python script export
- Git branching, commits, Pull Requests, and conflict resolution

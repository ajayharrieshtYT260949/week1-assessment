# Week 1 Assessment — Python and Data Engineering

This repository contains the Week 1 assessment tasks completed as part of a Python, data engineering, and data analysis learning program. It demonstrates Python fundamentals, object-oriented programming, file handling, API integration, data manipulation, visualization, and Git-based version control.

## Tasks Overview

- **Task 1 — Python Core and OOP:** Python fundamentals, functions, and object-oriented programming concepts.
- **Task 2 — File Handling and API Integration:** File operations, working with APIs, JSON data, environment variables, and request timeouts.
- **Task 3 — NumPy, Pandas, and Matplotlib:** Data cleaning, transformation, joins, department-level analysis, and data visualization.
- **Task 4 — Git, Terminal, and Jupyter Notebook:** Terminal-based file operations, notebook-based employee data analysis, report generation, and Git branching workflow.

## Technologies and Tools

- Python
- NumPy and Pandas
- Matplotlib
- Jupyter Notebook
- REST APIs and JSON
- Git and GitHub
- VS Code and PowerShell

## Repository Structure

Each task is maintained in its own folder with a dedicated README, source files, and relevant outputs or supporting resources.

## Version Control Workflow

The assessment uses a feature branch named `feature/analysis` to organize development and demonstrate commits, branch management, Pull Requests, and README merge-conflict resolution.

## Purpose

The goal of this repository is to demonstrate practical Python programming, data analysis, API usage, reproducible workflows, and collaborative version control practices.

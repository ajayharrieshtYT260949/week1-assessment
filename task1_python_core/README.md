
# Task 1 — Python Core, OOP and Errors

## Objective
Demonstrate Python functions, object-oriented programming,
exception handling, comprehensions, lambda, map, filter and loops.

## Files
- `main.py` — implementation of all Task 1 requirements.
- `employees.csv` — the provided employee dataset.

## Run
```bash
python main.py
```

## Key concepts
- Functions with default arguments, *args and **kwargs
- Employee class and Manager inheritance
- Custom InvalidSalaryError exception
- CSV reading, list comprehension, map, lambda and filter
- try/except/finally, continue and break
